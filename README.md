This project contains the scripts and files for data processing, visualisation, and analysis for the survey and experimental studies related to subjective assessment of sleepiness and alertness.

There is not a single pipeline to run; different scripts have to be run separately.

Python scripts were prepared with the help of ChatGPT (different versions), and were reviewed and supervised.

Processed datasets with outcomes are publicly available at https://doi.org/10.58132/IPTYHJ (experimental study) and https://doi.org/10.58132/QYEMKU (survey study).
